# C3 重建 v2：简明结论

已经完成第 1–404 圈的模型重建。末层没有拟合充分的问题已解决；重新选择特征后，中间隐藏点的误差比旧版小，但仍不如线性插值。当前曲线可作研究性估计，不能当作逐圈实测 SOH 标签。

## 实际用了什么方法

保留 Che 论文的容量重建路线：从部分充电曲线提取健康特征，用源电池训练一层 LSTM＋输出层，再用 C3 的少量 RPT 容量点只校准输出层。不做未来寿命预测，不解冻 LSTM，不用插值修补输出，也不强制曲线单调。

这次没有照搬标准差、熵和第一主成分。在预先固定的 18 个电压窗口中，9 个通过数据覆盖检查，形成 81 个候选特征；按相关性、方向一致性及冗余规则筛选。最终全点重建选中：

1. **3.6–3.8 V 之间的充电电量**，除以额定容量。
2. **3.6–3.8 V 内各小电压段充电电量的下四分位数**，也就是这些分段电量中位于 25% 位置的值。
3. **3.5–3.9 V 内各小电压段充电电量的中位数**。

源域仍是固定的三枚 MICH 训练电池和一枚独立验证电池。最终窗口交集保留 1133 个训练循环和 443 个验证循环。按源域验证结果选择的最终网络宽度为 32，输入过去及当前共 20 圈的特征，三个随机种子分别训练。所有场景合计完成 216 次源域选型运行，没有未收敛项。

论文没有公开完整网络参数或自动特征搜索算法。上述窗口搜索、筛选门槛及补充参数属于明确披露的 C3 任务适配，不是作者原实验的严格复现。

## 效果到底怎样

验证时，每次先隐藏一组 RPT 容量，再重新筛选特征、训练源模型、校准输出层，最后预测被隐藏点；401/402 圈同时隐藏。最终用全部六点校准的曲线不作为测试成绩。

在共同隐藏的 **101、201、301 圈**，三种子平均绝对误差如下。单位为 **SOH 百分点**，例如 95.0% 预测成 95.4%，误差就是 0.4 个百分点。

| 方法 | 平均绝对误差，越小越好 |
|---|---:|
| v2 神经网络重建 | 0.375 |
| 旧版神经网络重建 | 0.457 |
| 线性插值 | 0.189 |
| PCHIP 插值 | 0.426 |

新版比旧版的中间点误差约降低 **18%**，但没有超过线性插值。旧版没有同样的嵌套特征筛选，因此新旧差异用于诊断，不视为完全同条件的模型优劣证明。

端点外推更不可靠：把所有六个隐藏点都计入，新版三种子的平均 MAE 为 **1.139 个百分点**；第 1 圈被隐藏时，最差种子误差约 **6.1 个百分点**。因此不能把中间三点的 0.375 泛化成整条曲线每圈的误差。

## 校准和自检

- 输出层改为直接求解最小二乘最优解，并用另一种数值算法独立复核；最终六点校准的 RMSE 均小于 0.000001 个 SOH 百分点。这个拟合误差不等于隐藏点误差。
- 改动隐藏容量不改变该折的特征选择、源域输入及训练权重；标准化和 PCA 只用源域训练电池，LSTM 在目标校准时保持不变。
- 独立用 NumPy 重算六个场景、三个种子、全部 404 圈的保存权重预测，并从 CSV 复算指标，检查通过。
- 137 项测试通过，7 项依赖旧 Ridge 实验产物的测试跳过。707 个冻结结果文件、57 个受保护输入的哈希检查通过；原始文件、旧版结果及 BatteryLife benchmark 未变。
- C3 SOH＝完整 RPT 放电容量÷183 Ah，**不使用 0.94**。只有六个点是实测；403/404 圈位于末次校准点之后，已单列标记。

C3 的充电设定随 RPT 容量更新，过程曲线可能间接包含容量信息；本次检查不能消除这种混杂。一枚电池、五组 RPT 的验证也不足以证明两次 RPT 之间每一圈的真实精度。不根据这次隐藏点成绩继续反向调参。

```bash
dataset/.conda_envs/comac95/bin/python -m experiments.mixed95.c3_che_v2 audit --suite-id c3_che_20261026_v2
```

从零重跑时必须选择新的、含 `_v2` 的 suite-id，例如：

```bash
dataset/.conda_envs/comac95/bin/python -m experiments.mixed95.c3_che_v2 all --suite-id c3_che_repeat_v2
```

输出位于 `dataset/mixed95/<suite-id>`。分阶段入口支持 `extract/select/train/calibrate/validate/report/audit`；已经完成并冻结的报告及独立自检记录不覆盖。
